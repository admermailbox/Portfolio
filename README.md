# Admer Serojales — Audit & Accounting Portfolio

A professional portfolio for Admer Serojales, covering financial audit, IT audit, inventory audit, accounting, and internal controls.

## Website

After enabling GitHub Pages at **Settings → Pages → Deploy from a branch → main → /(root)**, the expected site address is:

https://admermailbox.github.io/Portfolio/

## Files

- `index.html` — portfolio content
- `styles.css` — design and responsive layout
- `script.js` — mobile navigation and footer

## Privacy

This public website lists the owner's own email, phone number, and city by request. It does not include third-party references or their contact details.

## Updates

Edit files on GitHub and commit to `main`; GitHub Pages will publish changes when Pages is enabled.
